# Original shrine assets

`source/` contains the supplied originals, organized by category with descriptive filenames. Preparation never overwrites these files.

Mobile-ready assets and previews live at `android/app/src/main/assets/shrine/`. The original-to-organized mapping is in `shared_assets/catalog/source-manifest.json`; build details are in `docs/ASSET_PIPELINE.md`.

`source/references/` holds the downloaded HTML reference, which is not an image and is not included in the app. `source/legacy/` preserves the unused original flame model.
