# Pavitra Mandir 1.0.7

Android version code: `8`

## Release notes

- Google sign-in provides clear retry messages for cancellation, unavailable
  credentials and connection failures.
- Inviting a friend opens a focused sign-in and WhatsApp sharing flow, with
  progress messages and protection against repeated taps.
- WhatsApp sharing supports WhatsApp Business and safely handles wrapped
  Activity contexts and missing apps.

## Release artifacts

- APK for direct installation: `android/app/build/outputs/apk/release/pavitra-mandir-1.0.7.apk`
- App bundle for Google Play: `android/app/build/outputs/bundle/release/pavitra-mandir-1.0.7.aab`
