# Pavitra Mandir 1.0.6

Android version code: `7`

## Suggested Play Store release notes

- Earn coins by completing your daily puja.
- Invite friends through WhatsApp and earn coins when a new user installs through your link and signs in with Google.
- Unlock new shrine designs and flower varieties with coins.
- Enjoy a playful mouse animation beside Lord Ganesha.
- Refined temple controls and bhajan player layout.

## Release artifacts

- APK for direct installation: `android/app/build/outputs/apk/release/pavitra-mandir-1.0.6.apk`
- App bundle for Google Play: `android/app/build/outputs/bundle/release/pavitra-mandir-1.0.6.aab`

The release uses the existing signing key and configured staging account backend.
